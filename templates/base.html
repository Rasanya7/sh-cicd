Connect Your GitHub Repository to Agentic Autofix

Follow this 4-step wizard to connect your GitHub repository. Once connected, whenever a build or test fails in GitHub Actions, SH-CICD will autonomously diagnose, fix, test, and open an Auto-Fixed Pull Request!

Step 1: Provide GitHub Personal Access Token (PAT)

Create a classic token at GitHub Developer Settings → Personal Access Tokens with repo and workflow scopes.

Step 2: Expose Local Server & Register Webhook
